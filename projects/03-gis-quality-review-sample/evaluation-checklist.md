# Evaluation Checklist

Use this checklist when reviewing AI-generated QGIS instructions or similar GIS guidance.

## Source clarity

- [ ] Data sources are named and appropriate for the task
- [ ] License, access, or download constraints are stated
- [ ] Time-sensitive data includes a date or refresh note

## Spatial correctness

- [ ] CRS is specified
- [ ] The projection is appropriate for the analysis
- [ ] Distance units match the CRS or are explicitly converted
- [ ] Geometry validity and clipping are addressed

## Workflow reproducibility

- [ ] Steps are ordered and specific
- [ ] QGIS tools are named clearly
- [ ] Inputs, outputs, and intermediate layers are identified
- [ ] Validation or QA steps are included

## Interpretation

- [ ] Claims match the method used
- [ ] Limitations are stated
- [ ] Confidence is not overstated

## Final delivery

- [ ] Map layout, labels, and export format are mentioned
- [ ] The answer is specific enough to reproduce
- [ ] The result does not rely on undefined assumptions
