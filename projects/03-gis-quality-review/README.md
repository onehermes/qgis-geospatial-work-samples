# GIS Quality Review - Evaluating AI-Generated QGIS Instructions

This review shows how I evaluate an AI-generated GIS answer before treating it as a workflow. The focus is on projection guidance, data-source clarity, unit handling, validation, and limitations.

## Objective

Demonstrate a practical review process for spotting weak GIS instructions and rewriting them into something reproducible and transparent.

## Related files

- [AI output review](ai-output-review.md)
- [Evaluation checklist](evaluation-checklist.md)

## Why this matters

A GIS answer can sound plausible and still be wrong if it omits CRS details, invents sources, or overstates what a buffer or overlay proves. This review shows a disciplined process rather than blind acceptance of generated instructions.
